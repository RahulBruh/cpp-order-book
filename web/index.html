Benchmark in your browser

same seeded order flow as the repo's lob_bench

Generates a seeded stream (53% add, 39% cancel, 8% modify, about 7% marketable) and replays it into a fresh std::map book and a fresh tick-array + bitset book, 3 times each, in a Web Worker. Both books must report the same trades.

Native results (GCC -O3, AMD Ryzen 5 7600): 58–63M msgs/s for the tick array vs 45–50M for std::map. WebAssembly in a browser tab runs slower than native, and the gap between the two books is smaller.
